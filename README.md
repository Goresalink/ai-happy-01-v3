# ai-happy-01 — Make the AI judge happy

## The image

A laughing blond child in denim overalls sits in a wildflower meadow
with a golden retriever puppy, colourful balloons drifting above them
in warm golden sunlight. It is a bright, warm, joyful scene, made to
make the judge smile.

## The program

`main.py` (Python 3.13, standard library only) copies the image stored
in this repository (`entry.png`) byte-for-byte to `/output/entry.png`
and verifies the copy is identical to the source.

Run it with:

    python3 main.py

## Files

- `main.py` — the entry program
- `entry.png` — the image (1024x1024 JPEG)
